# primer-pr

Repo de práctica para mi primer PR.

## Flujo de trabajo

1. Crear una rama nueva a partir de `main`.
2. Hacer los cambios y confirmarlos con un commit.
3. Subir la rama a GitHub con `git push`.
4. Abrir un pull request hacia `main`.
5. Revisar el PR y fusionarlo.

## Cómo correr los tests

No hace falta instalar nada: los tests usan `unittest`, que viene con Python.

```
python3 -m unittest -v
```
